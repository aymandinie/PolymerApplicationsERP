A rejected scan never reaches labour cost. Reused and out-of-sequence codes are logged for review.

Why the code changes

  • 1Bound to one action. A check-in code cannot be used to check out.
  • 2Single use. The moment it is scanned it is consumed and dies.
  • 3Expires in 90 seconds. A photographed screen is worthless a minute later.
  • 4Bound to the worker. The badge number is inside the payload, so it cannot be passed to a colleague.
  • 5Sequenced. Break end cannot fire before break start.
This is what stops buddy-punching, the single largest source of inflated foreign-worker hours.
